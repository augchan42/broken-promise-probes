Qwen neuron comparison

Can we tell from inside Qwen whether it was asked to lie or whether it actually gave a false answer? On each fictional board, we show Qwen an occupied or empty fort and ask for a truthful or false answer. The viewer compares three internal units, called neurons, as Qwen reads each prompt.

Where to start

Choose Lake Keep and click Largest gap. Compare the two prompts with the same board state. Qwen answered truthfully on Lake Keep even when asked to lie. A gap can reflect the change in wording, even when the answer stays the same.

What the bars measure

Each bar is one neuron's reading, called its activation, at one token (a word, part of a word, or punctuation). Orange is above zero and blue is below zero. Taller bars are farther from zero. All four charts use the same scale for the selected neuron and board.

How we found these neurons and what inspired the viewer

Where the idea came from

Our broader project asks whether Qwen's internal activity can help us spot broken promises in a diplomacy game. For this viewer we use a smaller experiment where we know the board state, the instruction and the answer Qwen gave.

Neuronary collects examples of how changing individual neuron readings alters a model's behavior. Its companion explorer made it possible to search and inspect individual units. That gave us a starting question for Qwen3.5-27B. Could any unit help us tell when a model was asked to give a false answer? Neuronary and its explorer

Drowse inspired clicking through text and following one unit over time. Neuron Lens inspired the two views we call Fires on and Writes. One shows what the model was reading when the unit was active. The other asks which output text its activity might favor. The readings on this page come from our own Qwen3.5-27B runs. Drowse · Neuron Lens findings

How we chose the three neurons

  1. We measured 1,114,112 neurons across 64 blocks at the last input token before Qwen answered.
  2. We ranked them using five prompt pairs. Both prompts in each pair produced the same Yes or No answer. One asked for the truth and the other asked for a false answer. We favored units with a gap in the same direction across all five pairs, large relative to how much that unit varied across the prompts.
  3. We kept the top three and checked them on four more pairs and two pairs whose prompts had the same token count. All three kept the direction of their original gap in those six pairs. That screen tests sensitivity to the instruction and leaves open which part of the prompt each neuron responds to.

How we used the MCP

MCP stands for Model Context Protocol. It lets an assistant ask a local tool for specific readings from our saved runs. The analysis script ranked the neurons. We used the MCP to look through their readings one token at a time and check where the prompts and the readings first differed.

For example, we asked the tool to compare neuron 8497 on Lake Keep while holding the board state fixed. The readings matched until the instruction changed. The largest gap on both board states came at a comma later in the prompt. Qwen gave the same answer under both instructions for each board state. The identical comma shows how earlier wording can affect the reading at a later token.

Precision check

When removing a reading seems to make a tiny difference, is it a real effect in the replay or an artifact of rounding? We ran the same check with Qwen's usual arithmetic (BF16) and with more precise arithmetic (FP32). Two unchanged copies ran alongside each edited copy to show how much the score could vary on its own.

BF16 stores numbers in coarser steps. A small change can cross a rounding boundary and show up as a whole step, or disappear if both values round to the same number. Rounding can happen at several stages. This check compares the final scores across precisions, so exactly where the difference arose is still open.

The table shows how much removing the reading changed the Yes versus No score. A negative effect means the original reading favored No. “Untouched score spread” is the variation among the copies we left alone. “Most likely start” shows whether Qwen's leading answer token changed.
